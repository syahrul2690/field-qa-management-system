## Overview & Scope

The Project Quality Plan (Field) is the comprehensive field-level quality management document governing all quality assurance and quality control activities during the construction, installation, commissioning, and performance testing phases of the Bangkanai GEPP Stage 2 power plant project.

This document establishes:
- Quality objectives and acceptance criteria
- Field quality control procedures and methodologies
- Inspection and test point definitions (H/W/R/E points)
- Documentation and record-keeping requirements
- Non-conformance and corrective action procedures
- Quality authority and sign-off protocols
- Field QC team structure and responsibilities

## Quality Assurance and Quality Control Roles and Responsibilities

### Quality Control Involvement Roles (Recap from SQP)

#### **E: EXECUTE**
- Performs the inspection or test
- Sends notifications to all concerned parties
- Documents all results and findings
- Maintains quality records
- Typical: Contractor/Wärtsilä technician

#### **H: HOLD POINT** (Mandatory Witness)
- Authority to halt work until present
- Must approve in writing to proceed if absent
- Typical: Customer/PLN technical authority
- **Critical for:** Safety-critical, performance-critical, acceptance tests

#### **W: WITNESS POINT** (Optional Observer)
- May attend and observe testing
- Test may proceed without presence
- May provide written waiver of attendance
- Typical: Shared authority between parties
- **Used for:** Important but non-critical tests, load control verifications

#### **R: REVIEW**
- Reviews documentation and test results
- Approves completion of specified work
- Maintains approval records
- Typical: Quality manager, document control authority
- **Applied to:** All test certificates and acceptance documentation

### Installation Phase Quality Control (Weeks 5-25)

#### **Daily Field Quality Activities**

**Morning Briefing (Daily at 06:30)**
- Review day's planned activities
- Identify inspections and tests scheduled
- Confirm witness/hold point authority availability
- Review any outstanding non-conformances
- Discuss weather and schedule impacts

**Inspection and Test Preparation (Pre-Work)**
- Verify equipment and materials ready for inspection
- Confirm all referenced procedures available
- Verify test equipment calibrated and ready
- Notify all relevant parties of scheduled inspection

**Inspection Execution**
- Follow detailed inspection procedure step-by-step
- Record findings on standardized inspection forms
- Photograph defects or non-conformances
- Collect serial numbers, installation details, measurements
- Obtain required witness signatures

**Documentation Completion (Same Day)**
- Complete inspection forms with all details
- Attach photographs or sketches
- Classify findings: Conforming/Minor Non-Conformance/Major Non-Conformance
- Submit forms to QC documentation specialist
- File in project quality records

**Daily Quality Report (End of Day)**
- Summary of inspections completed
- Any non-conformances identified
- Hold point status (cleared/pending)
- Planned activities for next day

#### **Mechanical Installation Quality Points**

**Critical H-Point Inspections:**

1. **Engine Crankshaft Alignment (I112_92)**
   - Procedure: SCA 011-161 Installation Inspection
   - Tolerance: ±0.05 mm per 500 mm length
   - Measurement: Dial indicator on rotating crankshaft
   - Hold Point Authority: H (Wärtsilä, PT PP, PLN)
   - Documentation: Alignment certificate with measurements

2. **Engine Springs and Coupling Alignment (I112_10, I112_20)**
   - Procedure: SCA 011-161 Installation Inspection
   - Tolerance: Springs ±10mm, Coupling ±2 mm lateral
   - Measurement: Feeler gauge and dial indicator
   - Hold Point Authority: H (Wärtsilä, PT PP, PLN)
   - Documentation: Alignment report with photos

3. **Fuel Gas System Configuration (I215_00)**
   - Procedure: AAFG System Installation
   - Tolerance: Pressure settings per equipment manual
   - Test: Gas pressure reduction, safety shutoff functionality
   - Hold Point Authority: H (Wärtsilä, PT PP, PLN)
   - Documentation: System pressure test certificate

4. **Cooling Water Radiator Installations (I240_10, I240_12, I240_13, I240_14) x4**
   - Procedure: VCA 011-164 Installation Inspection
   - Tolerance: Alignment ±5 mm, bolting torque per spec
   - Measurement: Alignment levels, bolt torque verification
   - Hold Point Authority: H (each bank) (Wärtsilä, PT PP, PLN)
   - Documentation: Individual radiator alignment certificates x4

5. **Lube Oil Separator Unit (I220_40)**
   - Procedure: QBB 011-161 Installation Inspection
   - Tolerance: Mounting bolts torque spec compliance
   - Test: Pressure drop and filter element integrity
   - Hold Point Authority: H (Wärtsilä, PT PP, PLN)
   - Documentation: Separator system inspection report

6. **Air Intake System - Charge Air Filter (I250_20)**
   - Procedure: NGA 010 B001-160 Installation
   - Tolerance: Filter seal integrity, no bypass air
   - Test: Pressure differential across filter element
   - Hold Point Authority: H (Wärtsilä, PT PP, PLN)
   - Documentation: Air intake system certification

#### **Electrical Installation Quality Points**

**Installation Inspection Checklist (I-series):**

- Electrical cable (I300_10): Insulation resistance ≥100 MΩ, continuity check
- Earthing system (I113_20): Resistance <5 ohm per AEGT011-161
- Control panels (I420_10, I420_20, I420_30): Electrical continuity, terminal torque
- Switchgear installation (I310_20): Mechanical operation, contact resistance
- Outdoor switchyard (I350_11, I350_12, I350_20): Foundation, alignment, mechanical function

**Test Execution Procedure:**
- Pre-test document review and procedure walkthrough
- Equipment setup and calibration verification
- Baseline reading documentation
- Test execution per procedure with data logging
- Final reading documentation
- Pass/Fail determination and record completion

### Functional Testing Phase Quality Control (Weeks 26-36)

#### **Functional Test Procedures**

**Standard Functional Test Methodology:**

1. **Pre-Test Review Meeting**
   - Confirm test procedure and acceptance criteria
   - Verify all prerequisite inspections completed
   - Brief all personnel on test sequence
   - Confirm witness/hold point authorities present

2. **Equipment Preparation**
   - Verify all components installed and accessible
   - Confirm auxiliary systems operational (cooling, instrumentation)
   - Initialize measurement and recording equipment
   - Establish communication protocols for safety

3. **Baseline Data Collection**
   - Record system temperatures, pressures, flows at zero load
   - Verify nominal operating parameters
   - Document initial equipment condition
   - Take baseline photographs

4. **Functional Test Execution**
   - Ramp up systems according to procedure
   - Monitor parameters continuously during operation
   - Log data at specified intervals (typically 15-30 min)
   - Observe for abnormal operations, noise, vibration
   - Execute any load steps or transient tests specified

5. **Data Analysis and Results**
   - Verify parameters within acceptance ranges
   - Identify any anomalies or out-of-spec conditions
   - Determine pass/fail status
   - Prepare test results summary

6. **Post-Test Documentation**
   - Complete functional test report form
   - Attach data plots and analysis results
   - Photograph final conditions if notable
   - Obtain witness signatures
   - Route for approval per sign-off matrix

#### **Functional Testing Categories**

**F1: Genset Functionality Tests**
- Engine instrumentation verification (F113_38, F113_39)
- UNIC C3 precommissioning for dual-fuel (F113_43)
- Engine safety module functionality (F113_60)
- Engine first start and safety procedures (F113_82)
- Synchronization control testing (F113_83)
- Alternator precommissioning (F120_12)
- Protection relay functionality (F120_15, F120_16)

**F2: Auxiliary System Functional Tests**
- Fuel oil system functionality (F211 series)
- Fuel gas system operation (F215 series)
- Lube oil system circulation (F220 series)
- Compressed air system operation (F230 series)
- Cooling water flow and temperature (F240 series)
- Air intake system verification (F250 series)
- Exhaust gas system function (F260 series)

**F3: Electrical System Functional Tests**
- Main switchgear operation (F310_20)
- Low voltage system ventilation (F320_91, F320_92, F320_93)
- Outdoor switchyard breaker operation (F350 series)

**F4: Control System Functional Tests**
- Operator station UPS system (F410_20)
- Control panel functionality (F420 series)
- Automatic voltage regulator settings (F424_10)

**F6: Emission Control Functional Tests**
- Continuous emission monitoring system (F600_50)

### Performance Testing and Acceptance Phase (Weeks 37-48)

#### **Performance Test Execution Framework**

**Critical Performance Tests with Hold Points:**

**1. Genset Power Output Test (C000_02) - H-Point**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | C000 011-161 |
| **Test Type** | Plant/Genset Performance Test |
| **Hold Point Status** | **YES - Both PT PP and PLN** |
| **Duration** | 2-3 days minimum |
| **Measurement Points** | Active power, reactive power, frequency, voltage, power factor |
| **Acceptance Criterion** | Power output within ±3% of design nameplate |
| **Documentation** | Test certificate with power curves, load steps, stability data |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (H) |

**Test Procedure:**
1. System warm-up at low load (15-30 min)
2. Incremental load steps: 25%, 50%, 75%, 100% of rated capacity
3. Hold at each step for 30 min with data logging (1 min intervals)
4. Record power, frequency, voltage, current per phase
5. Perform load impact test (sudden ±10% load change)
6. Document power factor and harmonic content
7. Verify no excursions beyond acceptable limits

**2. Lube Oil Consumption Test (C000_05) - H-Point**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | SCA 011-161 |
| **Test Type** | Engine Performance Test |
| **Hold Point Status** | **YES - Both PT PP and PLN** |
| **Test Duration** | Minimum 72 hours of continuous operation |
| **Measurement** | Oil level change (mL) over 100 operating hours |
| **Acceptance Criterion** | <0.5% of total oil capacity per 100 hours |
| **Documentation** | Oil consumption certificate with trending data |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (H) |

**3. Heat Rate Test (C000_12) - H-Point**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | C000 011-161 |
| **Test Type** | Genset Performance Test |
| **Hold Point Status** | **YES - Both PT PP and PLN** |
| **Fuel Consumption Measurement** | Flow meters (±2% accuracy) |
| **Efficiency Reference** | Compare to vendor guarantee (typical: ~45% gross efficiency) |
| **Acceptance Criterion** | Heat rate within +5% of vendor guarantee |
| **Documentation** | Heat rate certificate with fuel consumption data |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (H) |

**4. Noise Level Test (C000_16) - H-Point/Review**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | C000 011-161 |
| **Test Type** | Genset/Plant Performance Test |
| **Hold Point Status** | **YES PT PP (H), REVIEW PLN (R)** |
| **Measurement** | Sound level at 1 meter distance per ISO 3744 |
| **Acceptance Criterion** | ≤95 dB(A) at full load (per contract specification) |
| **Measurement Points** | North, South, East, West sides of equipment |
| **Documentation** | Noise level certificate with measurement locations |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (R) |

**5. Emissions Level Test (C000_17) - H-Point/Review**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | C000 011-161 |
| **Test Type** | Genset/Plant Performance Test |
| **Hold Point Status** | **YES PT PP (H), REVIEW PLN (R)** |
| **Pollutants Measured** | NOx, CO, CO₂, PM (per IEC 60551 or local regulation) |
| **Acceptance Criterion** | Per environmental permit and contract specification |
| **Stack Sampling** | CEMS or periodic sampling per protocol |
| **Documentation** | Emissions certificate with test conditions and results |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (R) |

**6. Reliability Test (C000_19) - H-Point**

| Aspect | Requirement |
|--------|------------|
| **Test Code** | C000 011-161 |
| **Test Type** | Genset/Plant Performance Test |
| **Hold Point Status** | **YES - Both PT PP and PLN** |
| **Duration** | Minimum 168 hours (1 week) continuous operation |
| **Load Profile** | 75%-100% rated load with random load steps |
| **Acceptance Criterion** | Zero unplanned shutdowns; <2 hours forced outage |
| **Documentation** | Reliability test certificate with operation log |
| **Authority Signatures** | Wärtsilä (E), PT PP (H), PLN (H) |

#### **Performance Test Data Collection**

**Instrumentation Requirements:**
- Temperature sensors (thermocouples or RTDs): ±0.5°C accuracy
- Pressure transducers: ±0.5% FS accuracy
- Flow meters (fuel, cooling water): ±2% accuracy
- Power analyzer (three-phase): ±0.5% accuracy
- Vibration sensors: ISO 10816 compliant
- Sound level meters: Class 1, ±1 dB accuracy

**Data Logging:**
- Continuous automated logging at 1-minute intervals minimum
- Manual data recording at 15-minute intervals
- Backup paper logs maintained
- Real-time display for test operator monitoring
- Digital backup (USB drive, cloud storage)

#### **Performance Test Hold Point Release Process**

1. **Test Execution Completion**
   - All test steps completed per procedure
   - All data collected and verified
   - No obvious equipment problems observed

2. **Preliminary Data Review (Wärtsilä)**
   - Data checked for completeness and validity
   - Calculations verified
   - Initial pass/fail determination
   - Any issues identified for resolution

3. **Hold Point Authority Notification**
   - PT PP Hold Point Authority notified of results
   - PLN Hold Point Authority notified of results
   - Results provided in preliminary format within 24 hours

4. **Authority Review Period (2-3 days)**
   - Authorities review preliminary test results
   - May request additional data or clarification
   - May observe retest if results questioned
   - Document review and approval

5. **Hold Point Signature**
   - Authority signs off on official test certificate
   - Signatures obtained from:
     - Wärtsilä (E) - Executing authority
     - PT PP (H) - Hold point authority
     - PLN (H) - Hold point authority
   - Certificate entered into project records

6. **Release and Archiving**
   - Hold point released for next phase
   - Official certificate filed in permanent records
   - Copy distributed to all stakeholders
   - Included in project handover package

## Non-Conformance Management

### Non-Conformance Classification

**Minor Non-Conformance (Category 1)**
- Does not affect equipment function or safety
- Can be corrected without rework or system shutdown
- Example: Missing supplier nameplate, minor cosmetic damage
- **Resolution:** Correction + documentation
- **Authority:** QC Inspector approval
- **Timeline:** Complete within 1 week

**Major Non-Conformance (Category 2)**
- May affect equipment function or safety
- Requires rework or investigation
- Example: Out-of-tolerance alignment, component substitution
- **Resolution:** Formal root cause analysis and corrective action plan
- **Authority:** QA Lead and Customer (PT PP) approval
- **Timeline:** Complete within 2 weeks

**Critical Non-Conformance (Category 3)**
- Affects safety, performance, or contract compliance
- May require design change or equipment replacement
- Example: Structural deficiency, emissions exceedance, major misalignment
- **Resolution:** Formal NCR with engineering review and corrective action
- **Authority:** Project Manager and Hold Point Authority (PLN)
- **Timeline:** Complete within 30 days (may halt work)

### Non-Conformance Report (NCR) Process

**NCR Initiation:**
1. Inspector identifies non-conformance during inspection/test
2. Photographer documents defect (at least 2 photos from different angles)
3. NCR form prepared with:
   - Component/system affected
   - Detailed description of defect
   - Reference to specification/procedure violated
   - Severity classification
   - Impact on project timeline/cost

**NCR Routing:**
1. QC Documentation Specialist - Records in NCR register
2. QA Lead - Severity classification confirmation
3. PT PP QC Authority - Formal acknowledgment
4. Wärtsilä Engineering - Root cause analysis
5. Corrective action plan development
6. Customer approval of corrective action

**Corrective Action Implementation:**
- Corrective action executed per approved plan
- Inspection of correction performed
- Photographic documentation of corrected condition
- Retest as needed per applicable procedure
- NCR closure documentation completed

**NCR Closure:**
- Final approval by PT PP and PLN (if critical)
- NCR closed in tracking system
- Added to project closure report
- Lessons learned documented

### Non-Conformance Trending

**Monthly NCR Summary:**
- Total NCRs opened
- NCRs by category (Minor/Major/Critical)
- NCRs closed
- Average closure time by category
- Trending graphs
- Root cause trending

## Quality Metrics and Performance Indicators

### Key Quality Metrics

**Installation Phase Metrics:**
- **H-Point Clearance Rate:** % of scheduled H-points cleared on first inspection
  - Target: ≥95%
  - Trending: Weekly
  - Action: <90% triggers engineering review

- **Inspection Schedule Compliance:** % of scheduled inspections completed on time
  - Target: ≥98%
  - Trending: Weekly
  - Action: <95% triggers resource evaluation

- **First-Pass Acceptance Rate:** % of completed inspections accepted without rework
  - Target: ≥90%
  - Trending: Monthly
  - Action: <85% triggers training or procedure review

**Functional Testing Phase Metrics:**
- **Test Execution Efficiency:** Actual vs. planned test duration
  - Target: ±5% variance
  - Tracking: Per major test
  - Action: >±10% variance triggers investigation

- **Functional Test Pass Rate:** % of functional tests passed on first attempt
  - Target: ≥95%
  - Tracking: Weekly summary
  - Action: <90% triggers root cause analysis

**Performance Testing Phase Metrics:**
- **Performance Compliance Rate:** % of performance tests meeting acceptance criteria
  - Target: 100%
  - Tracking: By test type
  - Action: Any failure triggers hold point authority meeting

- **Witness Availability:** % of critical tests with all required authorities present
  - Target: 100%
  - Tracking: Per test event
  - Action: <100% triggers scheduling improvement
