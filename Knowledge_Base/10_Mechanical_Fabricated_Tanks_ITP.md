## Overview & Scope

Inspection and Test Plans (ITP) for fabricated storage tanks define the complete quality assurance framework for both shop and site fabrication phases. These plans align with industry standards including API 650 (Welded Steel Tanks for Oil Storage) and ASME VIII (Pressure Vessels).

**Key Objective:** Ensure all fabrication and site erection activities meet contract requirements, engineering specifications, and applicable codes through systematic inspection and testing at critical control points.

**Document Status Codes:**
- **Status A:** Approved
- **Status B:** Approved as Noted  
- **Status C:** Not Approved
- **Status I:** Information Only

## Inspection Activity Matrix

### Responsibility Codes

- **P (Subcontractor):** Performs work and initial inspection
- **PP (Main Contractor):** Verifies subcontractor work, approves activity
- **H (Hold Point):** Work cannot proceed without Client/Owner acceptance
- **W (Witness):** Client/Owner attends inspection; work may proceed if Client/Owner absent at appointed time
- **SW (Spot Witness):** Random/spot inspection by Client/Owner
- **R (Review):** Review of documentation, certificates, reports
- **A (Approval):** Formal approval required on procedures/documents
- **IR (Issued Report):** Documentation required (Inspection Report, Mill Certificate, etc.)

## NDT & Test Parameters

### Non-Destructive Testing Methods

| Method | Code | Application | Acceptance Standard | Used For |
|--------|------|---|---|---|
| **Visual Inspection** | VI | All welds, surfaces, dimensions | API 650, ASME VIII | Initial assessment, cracks, porosity |
| **Penetrant Test** | PT | Joint welds, nozzle connections | **ASME VIII** | Surface-breaking defects (100% on nozzles) |
| **Radiography Test** | RT | Shell welds, critical joints | **API 650, ASME VIII** | Internal defects (voids, inclusions) |
| **Ultrasonic Test** | UT | Plate thickness, weld quality | ASME V | Subsurface defects |
| **Magnetic Particle Test** | MT | Ferrous material welds | ASME V | Surface & near-surface defects |
| **Vacuum Box Test** | VBT | Bottom seams, nozzle connections | **API 650** | Leak detection (100%) |
| **Hydrostatic Pressure Test** | HPT | Complete tank assembly | **API 650** | Pressure boundary integrity |

---

### Hydrostatic Test Parameters

| Parameter | Value | Reference | Acceptance |
|-----------|-------|-----------|---|
| **Test Pressure** | **1.5× Design Pressure** | **API 650** | No leakage, no permanent deformation |
| **Duration** | **Typically 24 hours** | API 650 | Sustained pressure, no degradation |
| **Acceptance Criteria** | **Zero Leakage** | **API 650** | No visible weeping or seepage |
| **Test Fluid** | Water (typically) | API 650 | Non-flammable, safe |
| **Certification** | MDR + Test Report | API 650 | Calibrated instruments, witnessed test |

## Acceptance Criteria

### Welding Quality Standards

**API 650 Weld Acceptance Criteria:**
- **Visual Defects:** No cracks, no undercut exceeding 1/32" (0.8 mm)
- **Porosity:** Scattered porosity acceptable if total area <5% in any 6" × 6" area
- **Inclusions:** Slag inclusions <1/8" (3 mm) single, <3/16" (4.8 mm) linear
- **Penetration Test (PT):** 100% of nozzle welds; linear indications >1/4" (6 mm) are rejectable
- **Radiography Test (RT):** 100% of shell body welds; acceptance per ASME Section VIII

### Material Acceptance

**Mill Certificates Required for:**
- All plate steel (chemical composition, mechanical properties)
- Electrodes and filler materials
- Fasteners (bolts, washers, studs)

**Overage, Shortage & Damage (OSD) Check:**
- Verify receipt against Packing List
- Inspect for transport damage, corrosion, deformation
- Document any discrepancies in receipt report

### Dimensional Tolerances

| Component | Tolerance Range | Reference | Acceptance |
|-----------|---|---|---|
| Tank Diameter | ±1/2" per 10' (±12 mm per 3 m) | API 650 | Pass if within tolerance |
| Vertical Alignment | ±1/4" per 10' (±6 mm per 3 m) | API 650 | Checked during erection |
| Roundness | ±2% of diameter | API 650 | Measured at shell/roof junction |
| Bottom Flatness | ±1/2" over 30' (±12 mm/9 m) | API 650 | Foundation leveling prior to testing |

## Applicable Standards & Codes

### Primary Standards

| Standard | Title | Applicability |
|----------|-------|---|
| **API 650** | Welded Tanks for Oil Storage | Vertical tank design, materials, fabrication, testing |
| **ASME Section VIII** | Pressure Vessels | Nozzle design, weld qualification, pressure testing |
| **ASME Section IX** | Welding & Brazing Qualification | WPS qualification, welder certification, PQR requirements |
| **ASME Section V** | Nondestructive Examination | NDT methods, penetrant test, ultrasonic, radiography |
| **AWS D1.1** | Structural Welding Code — Steel | Weld symbols, procedures, inspection |
| **AWWA D100** | Welded Carbon Steel Tanks for Water Storage | Vacuum box testing, internal examination |
| **ASTM A36** | Carbon Structural Steel | General material specification |
| **SSPC SP 6** | Commercial Blast Cleaning | Sandblasting preparation for painting |

### Supporting Documentation

- **PQR:** Procedure Qualification Record (welding)
- **WPS:** Weld Procedure Specification
- **WQTR:** Welder Qualification Test Record
- **NDT Procedure:** Per ASME Section V for PT, RT, UT
- **Mill Certificate:** Material composition & mechanical properties
- **MDR:** Manufacturer's Data Report (hydrostatic test certification)
- **NCR:** Non-Conformance Report (for deviations)
- **RFI:** Request for Information (clarifications)
