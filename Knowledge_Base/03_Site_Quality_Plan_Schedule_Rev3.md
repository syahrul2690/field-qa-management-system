## Project Schedule Framework

### Phases and Quality Control Gates

The Bangkanai GEPP Stage 2 project is structured in multiple phases, each with integrated quality control gates:

#### **Phase 1: Pre-Installation & Preparation**
- Site preparation and equipment receiving
- Quality documentation review and approval
- Contractor training and mobilization
- Inspection equipment calibration
- Documentation systems setup

#### **Phase 2: Mechanical Installation**
- Engine block installation and alignment (**H-Point: Crankshaft Alignment**)
- Fuel systems installation (**H-Point: Gas System Configuration**)
- Lube oil systems installation (**H-Point: Separator Unit**)
- Cooling water systems installation (**H-Point: Radiator Alignment x4**)
- Air intake systems installation (**H-Point: Charge Air Filter**)
- Compressed air systems installation
- Auxiliary system installation

#### **Phase 3: Electrical Systems Installation**
- Generator and switchgear installation
- Main electrical switchboards installation
- Control panel installation
- LV cable routing and termination
- Protective relay systems installation
- Communication systems installation

#### **Phase 4: Control Systems Integration**
- Control system interconnection
- SCADA system installation
- Operator station setup
- Safety system integration
- Instrument air network installation

#### **Phase 5: Mechanical Functional Testing**
- Engine instrumentation verification
- Fuel system functional tests
- Lube oil circulation functional tests
- Cooling water flow verification
- Air intake system verification
- Compressed air system verification
- Engine safety system functional tests

#### **Phase 6: Electrical Functional Testing**
- Main switchgear functionality tests
- Protection relay functionality tests
- Voltage control system tests
- Low voltage system verification
- Control panel functionality tests

#### **Phase 7: Integrated Commissioning Tests**
- Engine first start and safety tests (**Witness Point**)
- Synchronization control and operation tests (**Witness Point**)
- Load control and droop mode verification (**Witness Point**)
- Load impact and rejection tests (**Witness Point**)
- Automatic voltage regulator testing
- Genset performance control verification

#### **Phase 8: Performance Verification Tests**
- **Power Output Test Certificate** (**H-Point: Both PT PP and PLN**)
- **Lube Oil Consumption Test Certificate** (**H-Point: Both Parties**)
- **Heat Rate Certificate** (**H-Point: Both Parties**)
- **Noise Level Testing** (**H-Point: PT PP, R: PLN**)
- **Emissions Level Testing** (**H-Point: PT PP, R: PLN**)
- **Reliability Test Certification** (**H-Point: Both Parties**)
- Vibration measurements and acceptance
- Operation data recording and documentation

#### **Phase 9: Commissioning and Handover**
- Final inspection walk-through
- All test certificates review and approval
- Operation data review and acceptance
- Training completion verification
- Final handover documentation

## Schedule Constraints and Buffer Management

### Schedule Constraints

**Fixed Constraints:**
- **H-Points:** Zero float; must be completed before progression
- **Design Finalization:** Drives SQP creation (4-week window)
- **Monsoon Season:** Weather-dependent activities may require acceleration
- **Grid Connection Coordination:** Performance tests coordinated with PLN schedule

**Resource Constraints:**
- Wärtsilä technician availability (from multiple projects)
- Customer inspection team availability
- PLN technical authority availability
- Subcontractor crew coordination

**Logical Dependencies:**
- Mechanical before electrical power-up
- All hold points cleared before witnesses released
- Functional tests before performance tests
- All tests before handover

### Schedule Buffer and Risk Management

**Key Buffer Periods:**
- H-Point Completion Buffer: 2-week float built into mechanical phase
- Functional Test Contingency: 1-week recovery for re-testing
- Weather Delays: 3-week contingency for external work
- Witness Availability: 2-week buffer for scheduling conflicts

**Critical Hold Points for Timeline:**
1. **Crankshaft Alignment Hold Point** - Clears mechanical foundation
2. **Gas System Configuration Hold Point** - Clears fuel system progress
3. **All Radiator Alignments (H x4)** - Clears cooling system validation
4. **Power Output Certificate (H-Point)** - Clears performance verification
5. **All Performance Tests Completed** - Gate to final handover

## Schedule Risk Management

### Schedule Risks and Mitigation

| Risk | Impact | Weeks | Mitigation | Buffer |
|------|--------|-------|-----------|--------|
| Witness unavailability | Hold point delay | 39-42 | Pre-schedule witness presence; backup authority | 2 weeks |
| Equipment damage during transport | Mechanical restart | 5-8 | Quality receiving inspection | 1 week |
| Weather delays (monsoon) | External work shutdown | Variable | Weather contingency buffer | 3 weeks |
| Test failures requiring rework | Schedule slip | 26-42 | Contingency test weeks | 1 week per 5-week phase |
| Design changes late in execution | Scope creep, delays | Weeks 5+ | Frozen design by Week 4 | 2-week recovery |
| Subcontractor performance | Multiple delays | Throughout | Weekly coordination meetings | 2-3 week contingency |

### Schedule Acceleration Options

If schedule compression is required:
- Parallel mechanical and electrical work (Week 5-25 overlap feasible)
- Pre-commissioning work during installation phase
- Extended working hours during critical path activities
- Backup test equipment and witness authorities
